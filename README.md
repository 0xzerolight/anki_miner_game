# Anki Miner Game

Records a video-game session through OBS and writes a same-stem `.mkv` + `.srt` pair, so [Anki Miner](https://github.com/0xzerolight/anki_miner) can mine it like an anime episode. Design: [`docs/specs/2026-09-20-anki-miner-game-design.md`](docs/specs/2026-09-20-anki-miner-game-design.md).
